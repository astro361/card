# therekk - Animated Business Card

Professional animated business card website for YASIR N, Computer Problem-Solving Expert from Cheruppulashery, Kerala.

## Features

- ✨ Glassmorphism design with blur effects
- 🎨 3D animations and interactive elements
- 📱 Fully responsive design
- 📧 Contact form with message storage
- 🎯 Smooth scroll animations
- 🔧 Service showcase
- 📊 About and statistics section

## Local Development

### Requirements
- Python 3.x
- Modern web browser

### Setup

1. Clone the repository:
```bash
git clone https://github.com/yasirnc/therekk-card.git
cd therekk-card
```

2. Run the development servers:

**Frontend (Terminal 1):**
```bash
python3 -m http.server 8000
```

**Backend (Terminal 2):**
```bash
python3 backend.py
```

3. Open http://localhost:8000 in your browser

## Deployment

### Deploy to Vercel

1. **Sign up** at [vercel.com](https://vercel.com)
2. **Connect your GitHub repository**
3. **Click Deploy** - Vercel will automatically detect and deploy your static site

**Messages Handling:**
- Contact form messages are sent to [Formspree](https://formspree.io)
- You'll receive all messages in your email inbox automatically
- Formspree is free and requires no backend setup
